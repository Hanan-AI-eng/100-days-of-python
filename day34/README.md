# Quiz App 🧠

A Python-based Quiz Application with a graphical user interface built using **Tkinter**.

This project was created as part of the **100 Days of Code: The Complete Python Pro Bootcamp**.

## 🚀 Features

- Multiple-choice quiz questions
- Graphical User Interface using Tkinter
- Displays one question at a time
- True/False answer buttons
- Tracks the player's score
- Shows whether the selected answer is correct
- Automatically moves to the next question
- Disables the quiz when all questions are completed
- Provides visual feedback for correct and incorrect answers

## 🛠️ Technologies Used

- Python
- Tkinter
- Object-Oriented Programming (OOP)
- REST API
- HTML entity unescaping
- Type hints
