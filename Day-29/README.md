# 🔐 MyPass - Password Manager

A simple desktop Password Manager built with **Python and Tkinter**.

MyPass allows users to generate strong random passwords, copy them to the clipboard, and save website login details into a local text file.

## ✨ Features

- 🔑 Generate random passwords
- 📋 Automatically copy generated passwords to the clipboard
- 🌐 Save website information
- 📧 Save email/username
- 🔒 Save passwords
- ⚠️ Warning message when required fields are empty
- ✅ Confirmation message before saving password details
- 🧹 Automatically clear the Website and Password fields after saving
- 🎯 Automatically focus on the Website field when the application starts

## 🛠️ Technologies Used

- **Python**
- **Tkinter** - Graphical User Interface
- **Random** - Password generation
- **Pyperclip** - Copy passwords to the clipboard
