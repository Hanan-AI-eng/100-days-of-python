# NATO Phonetic Alphabet

A Python project that converts a word entered by the user into its NATO phonetic alphabet code words.

## How It Works

The program:

1. Reads the NATO phonetic alphabet from a CSV file.
2. Creates a dictionary using the letters as keys and NATO code words as values.
3. Takes a word from the user.
4. Converts the input to uppercase.
5. Uses a list comprehension to convert each letter into its NATO phonetic code.
